## 新文件结构（最精简，按需增长）

```
project.godot            # autoload：EventManager、SaveManager、SettingsManager
addons/godot_mcp/        # gdmcp 工具链
assets/fonts/            # 像素字体（保留），其余待新角色资源
scenes/main/             # 游戏入口场景
scenes/player/           # 玩家场景
scenes/ui/               # 预留
scripts/managers/        # event_manager.gd（事件总线）
scripts/player/          # 玩家脚本
scripts/ui/              # 预留
```

约定：每新增一个功能模块，才新增对应目录与文件；不提前搭空壳。

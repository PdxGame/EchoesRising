## 2. 一句话概念

一架世界回应总迟到的“迟响天梯”，玩家要一路向上，利用普通地形、单向木板和发条弹簧爬向高处。失误不会死，只会从更高处摔回下方；历史最高高度和存档位置，是玩家“曾经到达过这里”的回响。

参考体验：Jump King 的失败代价与小心起跳 + Icy Tower 的纵向目标 + 马里奥的明快跳跃手感。

## 3. 核心循环

```text
观察路线 → 起跳 → 踩平台/借弹簧 → 爬得更高 → 失误掉落 → 回到下方继续挑战
```

玩家的进度压力来自“爬高后的失误代价”，而不是生命值。

设计底线：

- 所有跳跃距离必须和当前跳跃能力匹配，不能出现规则内无法到达的平台。
- 失败原因要能被玩家理解，不允许弹簧误触发或隐藏碰撞。
- 地图每段应提供足够宽的“观察台”，让玩家判断下一步再跳。
- 不做死亡，不做扣血，不做必须重开的流程。

## 4. 主题解读：「滞后」

主题不靠文字硬讲，而靠“世界反应比玩家慢”来表达。

当前最核心的回响：

- 历史最高高度：代表玩家曾经到达的位置，比当前身体所在更高。
- 存档位置：退出后重新进入，世界仍然记得你上次停下的地方。
- 弹簧压缩：动作发生在一瞬间，但视觉和上升反馈会短暂延后。

建议主钩子：

- 将天梯设定为“迟响天梯”：玩家每到达一段新高度，身后会有钟声、光点或回响延迟亮起。
- 地图中多使用按钮、门、延迟平台这类“按下后不立刻生效”的机关。
- 蓝色按钮最适合做第一个主题机关：按下后延迟约 0.5~1 秒再激活目标，让玩家体会“滞”。

## 5. 地图主题设计建议

整张地图建议是一根纵向塔，而不是横向关卡。按高度拆成三段，美术和机关节奏逐渐变化。

### 第一段：迟来的花园

- 高度：0~约 40m
- 视觉：草地、泥土、木平台、矮塔基
- 目标：教学与热身
- 内容：
  - 宽实心地面和宽单向平台
  - 平台间隔小，确保失败也能快速回到底层
  - 第一个弹簧放在容易看清的位置
  - 开始熟悉“当前高度 / 最高高度”概念

### 第二段：回响钟楼

- 高度：约 40~90m
- 视觉：砖块、蓝色块、木板、钟楼内部
- 目标：主题核心与第一个机关段
- 内容：
  - 开始使用窄一些的单向木板
  - 增加需要左右判断的错位平台
  - 蓝色按钮可放在宽阔观察台上
  - 按钮延迟激活上层桥/平台，制造“回应迟迟才到”的感觉
  - 弹簧用于补偿较高落差

### 第三段：错时星空

- 高度：约 90~150m
- 视觉：深蓝、紫、星空、云顶
- 目标：最终挑战
- 内容：
  - 平台更窄、间隔更准确
  - 用弹簧设计连续上升链
  - 失误可能掉回钟楼中段，而不是塔底
  - 不再需要新的复杂机关，以手感考验为主

以上高度和米数只是建议，最终以玩家实际手感为准。地图由用户设计摆放，Agent 负责把可复用机关做好。

## 6. 跳跃与平台数值建议

当前跳跃参数：

- 单次最大跳跃高度约 209px
- 跳跃力：-640
- 重力：980
- 最大下落速度：1200

地图摆放建议：

- 舒适平台垂直间距：120~160px
- 挑战平台垂直间距：160~190px
- 避免常规平台间距超过 200px
- 平台水平错位不能大到玩家在空中完全无法判断下一落点
- 单向木板是主要可站平台，不要把它当普通墙体

如果地图希望增加更大落差，应使用弹簧，而不是直接拉大普通跳跃距离。

## 8. 存档与高度

当前已实现：

- HUD 左上角显示当前高度与最高高度。
- 当前高度按角色脚底相对地图零点计算。
- 退出游戏时保存当前玩家位置。
- 下次启动从存档位置开始。

若地图零点改变，应同步调整 `HeightHUD.origin_y`。

存档只记录“退出时的当前位置”，不是最高点，也不是失败重生点。

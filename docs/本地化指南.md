# 本地化指南

项目使用 Godot 原生 `TranslationServer`。中文是场景和脚本中的源文本，英文翻译保存在：

```text
res://localization/en.po
```

## 玩家切换方式

主菜单进入“设置”，在“语言”选项中选择：

- `中文`
- `English`

语言选择会立即生效，并保存到 `user://settings.cfg`。

## 新增或修改文本

1. 在场景、脚本或 `resources/npc_dialogue_bank.tres` 中保留中文源文本。
2. 在 `localization/en.po` 中添加对应的 `msgid` 和 `msgstr`。
3. `msgid` 必须和源文本完全一致。
4. 多行文本使用 `\n` 表示换行。
5. 带变量的文本保留相同占位符，例如 `%s` 和 `%.1f`。

示例：

```po
msgid "新游戏"
msgstr "New Game"
```

## 实现约定

- 场景里的 `Label`、`Button`、`CheckButton` 等静态文字由 Godot 自动翻译。
- HUD、机关倒计时、NPC 台词和结局台词在脚本中显式调用 `tr()`。
- 不写 `if language == "en"` 之类的分支；所有语言差异统一进入 `.po`。
- 英文项目名配置在 `project.godot` 的 `application/config/name_localized`。

# 文档目录

本目录存放《滞变》的正式文档与开发执行文档，按商业开发模式管理。

## 文件说明

| 文件 | 用途 | 打开方式 |
| --- | --- | --- |
| GodotHubFestival2026_滞变_策划案_v1.0.docx | 正式策划案（定稿/评审版） | Word / WPS |
| GodotHubFestival2026_滞变_策划案_v1.0.pdf | 策划案只读版 | PDF 阅读器 |
| GodotHubFestival2026_滞变_数值表_v1.0.xlsx | 玩家/机关/道具/关卡/排期数值 | Excel / WPS |
| 滞变_开发流程图.mmd | 开发流程 Mermaid 源文件 | 文本编辑器或 mermaid.live |
| 开发路线图_v1.md | 总规划与每周计划（执行版） | 文本编辑器 / Markdown |

## 约定

- Word/PDF 是正式定稿与评审用文档；Markdown 是开发执行版，随进度更新。
- 每次里程碑完成，更新本目录对应文档并提交到 Git。
- 数值以 Excel 表为准，代码实现与 Excel 不一致时，先改表再改代码。

## Git 分支约定

- `main`：稳定版，只放通过验证的版本，发布前打 tag。
- `dev`：日常开发线，功能先在这里开发与测试。
- `feature/prototype`：试验性功能或高风险改动，确认后再合入 `dev`。
- 流程：`dev` 开发 → 验证通过 → 合入 `main` → 打 tag 记录可发布版本。
- 正式开发前由你创建 GitHub 仓库，配置远程地址后按此流程推送。

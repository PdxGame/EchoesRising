## 每周规划

### 第 1 周（08/09 - 08/15）：手感与核心原型

- 搭建 Godot 工程目录与场景结构（scenes/scripts/assets/docs）。
- 按 AGENTS.md 顺序搭建 8 个管理器框架（Event/Resource/Time/Audio/UI/Persistence/Level/Game）。
- 玩家 CharacterBody2D：A/D 移动、Space 跳跃，按数值表调手感。
- 延迟平台：踩按钮 → 1 秒后平台出现 → 亮 3 秒。
- 主菜单雏形、死亡与快速重生。
- 验证：gdmcp CLI 检查无错；手动试玩 10 分钟。

### 第 2 周（08/16 - 08/22）：机制与 L1/L2

- 拉杆门、滞后传送带、回声花。
- 黏液果、慢世界钟、闪光莓、光点收集。
- 荆棘藤、回声花粉 Debuff 与 HUD 倒计时。
- 完成 L1、L2 关卡制作。
- 验证：能完整玩两关，机制有清晰预告。

### 第 3 周（08/23 - 08/29）：六关成型

- 完成 L3-L6，按数值表落实难度曲线。
- 音效与粒子特效、UI 打磨。
- 存档（进度 + 最佳时间）、结算画面。
- 验证：全流程可玩，难度递增合理。

### 第 4 周（08/30 - 09/06）：打磨与提交

- 全面 Bug 修复、手感与节奏打磨。
- Windows 导出并自测；Web 版时间允许则补。
- 录制并发布视频（9/10 前）。
- 09/06 前完成官网提交。

## 风险与缓冲

- 手感不过关：第 1 周必须解决，不回炉到第 2 周。
- 内容做不完：优先砍 L6 与 Web 版，保住 5 关与 Windows 版。
- 滞后被当 Bug：所有滞后效果必须有预告和倒计时。

## 已定技术决策

- 地形：Godot 内置 TileMapLayer 在编辑器里手绘，瓦片集用脚本生成几何霓虹色块。
- 机关与道具：独立场景手动放置（按钮、门、延迟平台、传送带、回声花等）。
- 关卡参数：配置资源保存难度、延迟、收集点，不动地图。
